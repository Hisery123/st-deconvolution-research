# CARR-lite-V2 source snapshot

Imported from `TRUST_Deconv` on 2026-11-21. Paths under this folder mirror the source directory.

`CARR_lite_v2/` contains the Tangram-based implementation and the historical held-out metrics and gate summary. `CARR_lite_v2_52scenario/` contains the scenario runner and its companion modules. Neither the held-out run nor the 52-scenario workflow was rerun for this import.

Scripts may reference local Windows paths and require external inputs, baseline predictions and software dependencies. Raw input data, per-spot predictions, model artifacts and third-party source trees are outside this snapshot.
