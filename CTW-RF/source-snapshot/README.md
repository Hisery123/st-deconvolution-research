# CTW-RF source snapshot

Imported from `STdeconv_benchmark` on 2026-11-21. Paths under this folder mirror the source directory.

`methods/Fusion/` contains the fusion and plotting scripts. `evaluation & visualization/` contains the historical metric tables, weight exports and audit scripts. `data/groundtruth/` contains benchmark construction scripts. The full-fit and cross-validation exports remain historical outputs and have not been independently recomputed.

Scripts may reference local Windows paths and require external inputs, baseline predictions and software dependencies. Raw input data, per-spot predictions, model artifacts and third-party source trees are outside this snapshot.
