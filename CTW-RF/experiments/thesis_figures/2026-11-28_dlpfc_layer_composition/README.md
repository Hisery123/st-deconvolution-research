## 方法与证据边界

- 每个切片内按已有皮层注释汇总平均预测组成；跨切片**等权平均**（不是直接pool所有spot）。
- L1/L2各有8张有标签切片；L3/L4/L5/L6/WM各有12张。151669–151672缺少L1/L2标签，不能补零。
- 数据包含12张DLPFC切片，但切片**不是12个独立生物学重复**；本次未直接审计spot级数据、原始层标注元数据和供体ID映射。
- Visium没有与这些spot逐点配对的细胞组成真值。图件只能支持预测分布及方法间差异的**描述性分析**，不能推出CTW-SoftOpt在真实组织中更准确；不做显著性检验。
- 图中的7种细胞类型沿用源文件名称，未作未证实的组织学细分类推断。
- SVG为矢量文件且文字可编辑；PDF图可运行脚本生成。未打包字体文件。
